Bank Churn Model
A bank churn model is a tool that helps banks identify and predict which customers are likely to leave the bank.

Bank Churn Model 
       -helps the bank identify potential leavers.
       -helps banks optimize processes and marketing efforts.
       -helps banks improve brand perception.

In this project,
I used pandas to get access to the data.
Preprocessed the data to change.
Seperated the available data into training and testing data set.
Trained the data using Machine Learning algorithm.
Predicted churning for the test dataset and calculated accuracy fot the predicted values and original tested dataset values.
(For the splitting, model training and accuracy testing ,I used scikit-learn library)
